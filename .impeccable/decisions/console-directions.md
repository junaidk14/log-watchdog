# Console direction exploration

Scope: Log Watchdog dashboard; Operate mode; code-first. User confirms incident-first overview and a lightweight SRE operations console. Existing visual implementation: none.

Mechanism: connect a locally detected error-log spike to inspectable events and the notification attempts it caused.
Audience scene: a developer scanning a desktop console, moving from an abnormal interval to concrete evidence without losing service or time context.
Category rut: generic metric-card grid above a chart. Predictable opposite: decorative terminal imitation. Neither serves as the governing form.

## Grounded candidates, ordered by resonance

1. Incident workbench — a dispatch queue with a persistent evidence pane; operations staff recognize the immediate triage-to-detail relationship.
2. Instrument strip chart — shared time axes and reference bands from measurement instruments make observed-versus-expected behavior legible.
3. Shift handover ledger — timestamps, service names, changes, and next checks form a concise operational record.
4. Debugger workspace — synchronized source/evidence panes preserve investigation context while drilling down.
5. Rack inventory panel — service rows with stable location and explicit state support repeat scanning across a small fleet.
6. Signal status matrix — services crossed with evaluation windows reveal insufficient data and abnormal intervals without conflating them.
7. Flight event recorder — one chronological incident strip connects the measured signal, log evidence, and resulting deliveries.

Seed: 599165fc; assigned candidate 7. Full network-backed reference roll obtained after sandbox fallback. No UI implementation written before the roll.

## Challenger assessment

Axes: audience identification and product clarity, compared with Flight event recorder. Every fusion preserves product facts and the user's console requirement.

- Drawcord cape: evidence panels gather along a selected incident channel; declined on both axes because the fabric transformation obscures standard investigation navigation. Raise: one selection must synchronize all downstream evidence.
- Iridescent cloud edge: uncertainty bands surround an observation interval; declined on both axes because spectral state vocabulary obscures severity. Raise: reserve color for the smallest meaningful signal and state uncertainty explicitly.
- Cracktro queue: incident priority becomes depth and brightness; declined on both axes because drifting bitmap layers undermine log reading and stable severity labels. Raise: keep the active incident immobile and primary while secondary context recedes.
- Nixie counter: observed, expected, and delta values become fixed numeric banks; declined on both axes because quantities lead at the expense of incident evidence and tube styling adds interpretation. Raise: align numeric precision and units so comparisons require no mental reformatting.
- Cassette J-card: incident evidence and webhook attempts form two linked time-ordered lists; declined on both axes because side-flipping disrupts the required continuous investigation path. Raise: show duration and timestamp alignment consistently across logs and attempts.
- Pop sleeve: a single affected service anchors four investigation destinations; declined on both axes because poster hierarchy suppresses dense operational evidence. Raise: keep the navigation to four unmistakable destinations.

These are discipline transfers, not decorative borrowing. All declined references remain visible and adoptable on the decision page. Assigned direction and top-ranked workbench are the full options; conventional category layout remains the standing exit.
