# Domain docs

Use a single-context layout:
- CONTEXT.md at the repository root.
- Architecture decision records under docs/adr/.
- The material architectural decision log is `docs/adr/decisions.md`.

Before exploring, read CONTEXT.md and ADRs relevant to the work.
If absent, proceed silently; create them when domain terms or
architectural decisions are resolved through domain modeling.

Use glossary terms consistently in issues, code, and tests.
Flag conflicts with existing ADRs explicitly, citing the ADR
and explaining why its decision should be reconsidered.
